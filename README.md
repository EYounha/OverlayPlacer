# OverlayPlacer

AI 협업형 UI 레이아웃 배치 편집기.

AI가 생성한 레이아웃 JSON을 불러와 시각적으로 좌표·크기·계층을 조정하고,
조정 결과를 다시 JSON으로 내보내 AI가 실제 UI 코드를 구현하도록 하는 워크플로를 위한 도구입니다.
스크린샷을 오가며 말로 위치를 설명하는 대신, 정확한 수치를 편집기에서 직접 결정합니다.

## 워크플로

1. **명세 전달** — 편집기의 `도움말 → AI 연동 가이드`에서 서식 명세를 복사해 AI에게 전달합니다.
   (또는 [`docs/AI_GUIDE.md`](docs/AI_GUIDE.md) 링크를 알려줍니다.)
2. **레이아웃 생성** — AI가 명세에 맞는 레이아웃 JSON을 작성합니다.
3. **가져오기** — `파일 → 클립보드에서 가져오기` 또는 JSON 파일을 캔버스에 드래그합니다.
4. **조정** — 이동·크기·회전·앵커·계층을 시각적으로 편집합니다.
5. **내보내기** — `파일 → AI용 JSON 내보내기`(Ctrl+E) 결과를 AI에게 전달하면,
   AI가 확정된 좌표를 기준으로 대상 플랫폼의 UI 코드를 구현합니다.

## 주요 기능

- **다중 아트보드** — 데스크톱 · 모바일 · VR 패널 해상도 프리셋, 한 프로젝트에서 여러 화면 관리
- **정밀 배치** — 절대좌표(px) + 9점 앵커 + % 단위, 부모-자식 계층 좌표, 회전
- **치수선** — 두 요소 사이 또는 아트보드 가장자리까지의 간격을 재고, 숫자를 고쳐 그대로 이동.
  선을 클릭해 선택하고 인스펙터에서 방향·기준을 바꾸거나 삭제
- **겹침 선택** — 포개진 대상을 다시 클릭하거나 Alt+클릭하면 커서 옆에 목록이 떠 무엇을 고를지 선택
- **스마트 스냅** — 요소 경계·중앙(자손 포함), 이웃과 같은 간격, 같은 크기, 아트보드·가이드·격자
- **편집 도구** — Ctrl 다중 선택, 그룹, 정렬(선택 영역·부모·기준 개체)·등간격 분배·간격 지정,
  Z순서, 잠금·숨김, 가이드
- **참조 이미지** — 아트보드 배경에 스크린샷을 깔고 불투명도를 조절하며 실화면 기준 배치
- **메타데이터** — 요소별 자유 key-value로 폰트·역할 등 구현 힌트를 AI에게 전달
- **히스토리** — 실행 취소/다시 실행 200단계, 브라우저 자동 저장
- **입출력** — 프로젝트 파일(.opl.json), AI용 클린 JSON, 클립보드 복사/가져오기, 드래그 앤드 드롭

## 실행 · Windows

저장소 최상위의 배치 파일을 더블클릭하면 됩니다. 필요한 준비 작업은 각 파일이 알아서 처리합니다.

| 파일 | 하는 일 | 필요한 것 |
| --- | --- | --- |
| **실행-웹.bat** | 브라우저에서 바로 실행 | [Node.js](https://nodejs.org) |
| **실행-데스크톱.bat** | 데스크톱 창으로 실행 | Node.js + [Rust](https://rustup.rs) |
| **빌드-실행파일.bat** | 단독 실행 파일(exe) 생성 | Node.js + Rust |
| **깃허브에서-빌드.bat** | 소스를 받아와 exe까지 한 번에 | Node.js + Rust + [Git](https://git-scm.com/download/win) |

`깃허브에서-빌드.bat`은 저장소를 먼저 받아두지 않아도 됩니다. 이 파일 하나만
아무 폴더에 두고 실행하면 옆에 소스를 내려받아 빌드까지 진행하며, 두 번째부터는
바뀐 부분만 받아 다시 빌드합니다. 소스가 있는 브랜치를 자동으로 찾으므로
브랜치를 직접 지정할 필요가 없습니다.

배치 파일은 실행만 담당하고 실제 안내와 로직은 `scripts/*.ps1`(PowerShell)에
있습니다 — cmd.exe가 한글이 섞인 배치 본문을 바이트 단위로 잘못 읽는 문제를
피하기 위한 구조이므로, 배치 파일 본문에는 ASCII만 두어야 합니다.

첫 실행 시 의존성 설치와 앱 아이콘 생성이 자동으로 진행되며 몇 분 걸립니다.
Rust 컴파일이 포함되는 데스크톱 실행·빌드는 최초 1회에 10분 이상 소요될 수 있습니다.
빌드 결과는 `src-tauri/target/release/overlayplacer.exe` 하나이며, 설치 과정 없이
원하는 위치에 두고 그대로 실행하면 됩니다. 완료 시 해당 파일이 탐색기에 표시됩니다.

빌드 없이 받으려면 [릴리스](https://github.com/EYounha/OverlayPlacer/releases)에서
`overlayplacer.exe`를 내려받으면 됩니다.

## 실행 · 기타 환경

macOS·Linux 등 배치 파일을 쓸 수 없는 환경에서는 npm 스크립트를 직접 사용합니다.

```bash
npm install
npm run dev            # 개발 서버 (http://localhost:5173)
npm run build          # 정적 빌드 → dist/
npm run tauri:icon     # 앱 아이콘 생성 (최초 1회)
npm run tauri:dev      # 데스크톱 창에서 실행
npm run tauri:build    # 단독 실행 파일 빌드
```

웹 빌드 결과물(`dist/`)은 정적 파일이므로 GitHub Pages 등 어디에나 배포할 수 있습니다.

## 기술 구성

TypeScript + Vite, 런타임 의존성 없음. 문서 모델은 단일 JSON 트리이며
앵커·단위 변환, 월드 행렬, 스냅 계산은 `src/model/`에 분리되어 있습니다.
